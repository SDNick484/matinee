# Movie Wish List Implementation Plan

> **For agentic workers:** use superpowers:subagent-driven-development or superpowers:executing-plans. Checkbox steps.

**Goal:** A per-title want (format + note), Want-to-buy state, push to the family Wish Lists app, a Wanted view, and
MCP `get_wishlist` / `want_movie`. Schema v11.

**Spec:** `docs/superpowers/specs/2026-11-12-wishlist-design.md`

## Global constraints

- `SCHEMA_VERSION` `"10"` → `"11"`, one self-contained block at the end of `migrate()`; v1 to v10 keep every row.
- Editors only: routes under `/admin/api` with `@editor_required`; no `want`, `wanted_format` or `wishes` key in `/api`.
- `wishlist.py` is route-free, never imports `app`, and is in `_SPLIT_MODULES` and `installer/build.sh`.
- Two settings in `.env.example`, `add_setting`, and the init script `export` line.
- No live network in tests: TMDB fixtures, a stub HTTP server for the Wish Lists app, port 1 for "down".
- Commits: Conventional Commits, one logical change each.

## File structure

- `db.py` (`SCHEMA_VERSION`, `NOTE_MAX`, v11 block), `settings.py` (two settings), `wishlist.py` (new), `app.py`
  (`ensure_title`, routes, clearing, re-exports), `browse.py` (`title_detail` private branch),
  `mcp_server.py`, `static/js/wishlist.js` (new), `detail.js`, `forms.js`, `router.js`, `static/style.css`.
- Tests: `tests/test_wishlist.py`, `tests/test_wishlist_ui.py` (in `tests/test_people_ui.py`'s job), edits to
  `test_privacy.py`, `test_mcp_server.py`, `test_mcp_http.py`, `test_installer_static.py` and the schema-version pins.
