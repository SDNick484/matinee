# AI search ("Ask") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Editors can ask the collection plain-language questions at `/admin#/ask` and get a short answer plus rows of real titles with their shelf or service. The rows come from a bounded Claude Haiku tool-use loop over `MatineeClient`'s DB-mode reads.

**Architecture:** Three additive fixes make `mcp_server.MatineeClient`'s DB mode fit for Ask: word-by-word search, `location_path` on copies, and the title `id` in `where_is`. `app.py` gains the v8 `ask_log` table and `title_cards()`, which shares its row-building with `list_titles`. A new `ask.py` owns the route, thread validation, daily cap, the Messages API call (`urllib`), a fail-closed `LocalClient`, the read-only tool table, the loop and the hydration of `show_results`. The SPA gains a `#/ask` view with compact result rows.

**Tech Stack:** Python 3.10–3.13, Flask, SQLite (WAL), plain `urllib`; vanilla JS; pytest; Playwright only for one optional smoke test.

**Spec:** `docs/superpowers/specs/2026-11-06-ai-search-design.md` is the source of truth. If the code contradicts it, stop and ask; don't redesign.

## Global Constraints

- Off unless `ANTHROPIC_SEARCH_KEY` is set. No fallback to `ANTHROPIC_API_KEY`.
- `ANTHROPIC_SEARCH_MODEL` defaults to `claude-haiku-5-5`. `ASK_DAILY_LIMIT` defaults to `200`; a non-integer value logs a warning and uses 200.
- Loop limits:
  - `MAX_ROUNDS = 5`, the 5th forced to `show_results`; also forced once summed input tokens exceed `INPUT_TOKEN_CEILING = 40000`.
  - `MAX_QUESTIONS = 5` per thread.
  - `BUDGET_S = 60` per question, `CALL_TIMEOUT_S = 25` per API call (or less if less time is left).
  - `MAX_TOKENS = 2048`.
  - `MAX_TOOL_RESULT_CHARS = 12000`.
  - 429 or 529 from the API is retried once after `time.sleep(2)`.
- Thread and answer sizes: `q` non-empty after `clean()` and ≤ 500 chars; `a` non-empty and ≤ 1,000 chars; `answer` cut to 600 chars; `title_ids` `maxItems` 12; `limit` clamped 1–25.
- Tools offered: exactly `search_collection`, `get_movie`, `where_is`, `get_recommendations`, `get_collection_stats`, `show_results`. The strings `rate_movie`, `log_watch`, `add_movie`, `search_tmdb` never appear in a request body.
- Schema: `SCHEMA_VERSION = "8"`. `ask_log` DDL lives only in `migrate()`, verbatim from spec §8. No existing table, column or row changes. Question text is never stored.
- No new runtime dependency (no SDK; `mcp` is not required by the app). No frontend build step. No `?v=` bump (`render_index()` hashes assets).
- Error bodies are `{"error": "<short message>"}` with the exact strings in spec §6. Details go to `app.logger` only.
- Tests make no live network calls. CI must stay green: Python 3.10–3.13 on Ubuntu, the Alpine job, `node -c static/app.js`.
- Commits: Conventional Commits, one per task, author `SDNick484 <SDNick484@users.noreply.github.com>`, on `feat/ai-search`. `python -m pytest -q` green after every task.

## Review Focus

1. **A title loses its last copy between the tool call and hydration** (an editor deletes it mid-question) → `title_cards` skips it; no 500. Test in Task 2 (`test_title_cards_skips_unowned`).
2. **The model passes `title_id` as `"17"` or `17.0`, or `limit: 500`** → coerced to `17`, limit clamped to 25; a bool `true` for `title_id` is refused with a tool error, not run as 1. Test in Task 4 (`test_run_tool_coerces_and_clamps`).
3. **A question about a title with odd characters** ("WALL·E", "Amélie", "Bug's Life") → DB-mode search folds it like the grid does. Test in Task 1 (`test_words_matches_app`).
4. **The phone sends Ask from the public view URL (`/#/ask`)** → the existing 404 view, no request to `/admin/api/ask`. Test in Task 7 (static check that `renderAsk` is reached only when `isAdmin`).
5. **The Anthropic API returns 200 with a non-object or no `content`** (proxy page, truncated JSON) → 502 with the standard message and `status=api_error`, not an HTML 500. Test in Task 5 (`test_non_object_response_is_502`).
