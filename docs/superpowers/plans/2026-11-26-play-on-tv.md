# Play on the Family Room TV and YouTube links: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A digital copy holds a YouTube video id, a one-time list load links the clean matches, and a ▶ (or an
assistant) starts an owned film on the Family Room TV through Home Assistant and logs the watch.

**Architecture:** Two new route-free sibling modules: `youtube.py` (the id rule, link parsing, list matching) and
`play.py` (what can play, the outbound Home Assistant call, who watched). Routes, `app.logger` calls and the watch
write stay in `app.py`. The front end gets one new ES module, `static/js/play.js`, used by the grid, the details
page and Movie Night. Nothing listens for the TV.

**Tech Stack:** Flask, SQLite, `urllib` (no new runtime dependency), vanilla ES modules, pytest, Playwright,
FastMCP for the last PR.

**Spec:** `docs/superpowers/specs/2026-11-26-play-on-tv-design.md`. Read it first; section numbers below (§) are
its sections.

## Global Constraints

- `CLAUDE.md` applies in full. The ones that bite here:
  - Schema changes only through idempotent `migrate()`; `SCHEMA_VERSION` becomes `"13"`; indexes on new columns are
    created in `migrate()`, not in `SCHEMA`.
  - A new sibling module never imports `app`, goes in `_SPLIT_MODULES` (`app.py`) and in `installer/build.sh`'s
    `cp` line, and `app.py` re-exports its names. Tests patch and read `app.X`.
  - No live network in tests. The Home Assistant call is tested with a stubbed `urllib.request.urlopen`
    (`conftest.FakeResponse`), including unreachable, timeout, HTTP 404 and HTTP 500.
  - Writes under `/admin/api/` with `@editor_required`. `tests/test_privacy.py` must pass.
  - New setting: `.env.example` (comment line above it), `installer/setup-head.sh` `add_setting`, and the
    `export` line of the app's init script.
  - Hygiene: `movies.example.com`, `192.168.1.100`, `media_player.family_room_tv` outside `docs/superpowers/`.
  - Conventional Commits, author `SDNick484 <SDNick484@users.noreply.github.com>`, one logical change each.
  - OpenRC and `vim` in docs.
- The id rule, everywhere: exactly 11 characters of `A-Z a-z 0-9 _ -`.
- `HA_PLAY_WEBHOOK_URL` is a secret: never logged, returned, or put in a payload; a log line names the host and
  the kind of failure only, never `str(exc)`.
- Nick's YouTube list and his Matinee export never enter the repo. Fixtures use well-known films with made-up ids.
- Nothing is created or changed in Home Assistant, and the TV is not turned on, without Nick's explicit go-ahead.
- Five PRs against `main`, none merged by the worker. Each PR ends with the Definition of done gate from
  `CLAUDE.md` (report the pytest skip count and reasons), then push, open the PR, wait for all seven CI jobs.
  Each PR branches from `main` once the one before it is merged; if it isn't merged yet, branch from the previous
  PR's branch and say so in the PR body.

## Review Focus

Inputs the spec implies but doesn't spell out. Each has a test in the task named.

1. **Links as people really paste them** (Task 2): `https://youtu.be/<id>?si=abc`, `…/watch?v=<id>&t=30s`,
   `…/watch?feature=share&v=<id>` (v not first), `m.youtube.com`, surrounding spaces or a trailing newline all
   store the id; `https://vimeo.com/123`, a 10 or 12 character id, and a playlist address with no `v` are a 400.
2. **The list file as exported** (Task 6): a UTF-8 byte-order mark on the CSV (Matinee's own export has one), a
   blank last line, `year` as a number or a string, a row missing `play_link`, an empty body, a body that isn't a
   list: a 400 with a sentence or a not-loaded row, never a 500.
3. **Ids that start with `-`** (Tasks 3 and 6): the export's `youtube_link` cell and the not-loaded CSV keep the
   full address intact; no cell is mangled by the formula guard.
4. **A stale page** (Task 8): the copy or its id was removed after the page loaded; the press is a 409 with a
   sentence and nothing is sent or logged.
5. **Which day is "today"** (Task 8): the watch is dated `pacific_today()`, and the movie-log event fires for it
   even when the host's own date differs; two presses either side of midnight log two watches.
