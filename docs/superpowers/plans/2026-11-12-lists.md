# Lists (Watch Soon and seasonal lists) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Curated lists of titles: a built-in Watch Soon list that drives the default recommendation and drops a
title once it is watched, plus editor-made seasonal lists, with public reads, editor writes, MCP tools and a
title-page UI.

**Architecture:** Two tables created in `migrate()` (schema v12). Stdlib-only `lists.py` holds the season logic,
queries and validation (raising `ListError`), shared by `app.py` routes, `recommend.py` and the MCP server's
direct-SQLite mode. The watch route deletes the Watch Soon row in its own transaction. A new ES module
`static/js/lists.js` renders the chips, the sheets and the manager.

**Spec:** `docs/superpowers/specs/2026-11-12-lists-design.md`

## Global Constraints

- `SCHEMA_VERSION` `"10"` → `"12"` (v11 is the wish list, #36, merged first). The lists step in `migrate()` is
  self-contained and runs for any database; a comment marks where the v11 step goes.
- No new dependency, setting or `$DATA_DIR` file. `lists.py` imports only the standard library (and `recommend`
  lazily).
- Writes under `/admin/api/` with `@editor_required`; reads under `/api/` and `/admin/api/` through the `_wrap`
  loop, so `PUBLIC_VIEW` applies. `seen_by` only on the editor read.
- Scenario titles: *Paddington 2* (TMDB 346648), *Spirited Away* (129), *Elf* (10719), *Hocus Pocus* (10439).
  New hand-written fixtures `movie-346648.json` and `movie-10439.json`.
- Commits: Conventional Commits, one logical change each, with the session trailers.
